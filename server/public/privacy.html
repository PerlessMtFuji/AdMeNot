Who is responsible

The data controller is Eryk Wlodarski. Contact: e.wlodarski@protonmail.com.

The AdMeNot program

Scans, reports and the action journal stay on your computer. The program sends none of them anywhere. The exceptions are error reports, which are sent only when you click “Send”, and usage statistics, sent only if you turn them on — both described below.

When “Check for updates automatically” is on (the default, in Settings → Updates), the program downloads a small file with version information from this website 10 seconds after it starts and then every 6 hours. The request carries nothing beyond a standard HTTP request with the header User-Agent: AdMeNot/<version>, and we store nothing from it. When you choose to install an update, the installer is downloaded from GitHub. With the setting off, the program makes no such connection — and will not learn about a new or withdrawn version.

The diagnostic command admenot selfcheck --online, which you run yourself, makes the same version request and calls /api/v1/health to check whether our server is reachable.

Error reports

When the program hits an unexpected error, or closed unexpectedly the last time, it offers to send an error report. A report is sent only when you click “Send”, and you can see its full content before sending. If there is no connection to the server at that moment, the program sends the report by itself once the connection is back.

A report always contains: the AdMeNot and Windows versions, the program language, a description of the error with its place in the program code, what the program was doing, the manufacturer, model and Android version of the connected phone, how many times the error occurred, and your optional description. Only if you tick the box does it also contain the last 50 ADB commands, which may include names of apps installed on the customer's phone.

A report never contains the phone's IMEI, serial number, phone numbers, e-mail addresses or your Windows account name — the program removes them before the report is saved on your computer. We do not store IP addresses.

We use reports only to fix errors in the program. Reports are deleted automatically after 90 days. To have one deleted earlier, write to the address above with the report number (for example R-7K3Q9M).

Usage statistics (optional)

Off by default. If you turn them on — on the first-start screen or later in Settings — the program sends anonymous usage statistics. The legal basis is your consent, Art. 6(1)(a) GDPR; you can withdraw it at any time.

  • Always: a random installation ID created when you consent, program and Windows version, language, the hour of the event.
  • Program start (at most once a day): simple or expert mode.
  • After a scan: phone manufacturer, model and Android version, number of apps per rating, scan time, APK analysis result.
  • After a repair: how many apps were silenced, disabled and removed, how many the program had flagged, how many failed, error codes.
  • After an undo: how many apps were restored and how many days after the repair.
  • Only with a separate second consent: package names of apps the program flagged or you selected, with the rating and your decision.

Never sent: serial number, IMEI, customer name, order number, shop details, screenshots, or names of apps rated safe that nobody touched.

The data is pseudonymous: it is linked to the installation ID, not to you or the customer. We keep it for 13 months. Turning statistics off in Settings deletes all data with your installation ID from the server (the program retries until it succeeds). You can also ask us by email to delete it — include the installation ID shown in Settings.

This website

The website uses no cookies, no analytics and no resources from other servers.

It is hosted by Cloudflare, which acts as our processor. Cloudflare sees your IP address when you connect, because that is how the internet works. We do not store or log IP addresses, and our code does not read them.

The installer is downloaded from GitHub, which has its own privacy statement.

Legal basis and transfers

We process this data to deliver the website and the server, keep them secure and fix errors reported from the program. The legal basis is our legitimate interest, Art. 6(1)(f) GDPR.

Cloudflare, Inc. is based in the United States, so data may be processed outside the EEA. The transfer is based on the EU–US Data Privacy Framework, in which Cloudflare participates.

We keep no data from visits. Cloudflare keeps technical data for the period set in its terms of service as our processor.

Rules for every future feature

  • We do not store IP addresses.
  • The IMEI, serial number, phone numbers and app list of a customer's phone are sent only with explicit consent at the moment of sending (for example, an error report you see before it is sent). The one exception: package names in usage statistics, only with a separate consent in the program that you can withdraw at any time.
  • Usage statistics (telemetry) only after you opt in.
  • Every new feature that sends data is added to this policy first.

Your rights

Under the GDPR you may ask for access to your data, its correction or deletion, restriction of its processing, its portability, and object to its processing. Write to the address above. You may also lodge a complaint with a supervisory authority — in Poland, the President of the Personal Data Protection Office (UODO).
