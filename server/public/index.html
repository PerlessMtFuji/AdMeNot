Remove adware from customers' phones

AdMeNot is a free Windows tool for phone repair shops. Connect an Android phone over USB: it finds the apps that show ads over other apps, explains why each one was flagged, and removes them, with undo.

One repair, start to finish

The customer says “ads keep popping up”. Here is what happens next.

Every flag comes with a reason

Each app gets a score from 0 to 100 and a confidence level. You see exactly which signals added up, for example:

  • Draws over other apps
  • Is a device administrator
  • Wakes the phone many times an hour
  • Was not installed from the Play Store
  • Has a name that imitates a system app

The ratings are heuristic: they say what an app does and how sure the program is, not that it is malware. You make the final call. How apps are rated

Careful with the customer's phone

  • Undo for every change

    A removed app is backed up on your computer first and can be reinstalled from History. Removal deletes the app's data, so the program warns you.

  • System apps stay locked

    Settings, the dialer, system UI and the installer can't be touched by accident. The active keyboard can be silenced but not disabled.

  • Find the real ad source

    When the culprit isn't obvious, reproduce the ad and click “Who is showing this?” to see which app owns the window.

  • Nothing hidden

    The ADB console shows every command sent to the phone. If the cable comes out mid-repair, reconnect and finish or undo the order.

What you need

  • A PC with Windows 10 or 11 (64-bit)
  • A USB cable for the phone
  • USB debugging turned on in the phone (Developer options)

Before you install

This is a beta. The installer is not digitally signed yet, so Windows SmartScreen may warn you. Click More info, then Run anyway.

The release notes of every version on GitHub list the SHA-256 checksum of the installer and its VirusTotal result.
