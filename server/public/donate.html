Support the project

AdMeNot is free and its source code is public. One person develops it in their spare time.

Support covers the project's costs, such as code signing for the installer and the server, and buys time for further work. It is entirely voluntary: it unlocks nothing, and the program works the same for everyone.

Support on suppi.pl

For now, support goes through suppi.pl, a Polish service (BLIK, bank transfer). The AdMeNot program sends no data there.
