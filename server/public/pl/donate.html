Wesprzyj projekt

AdMeNot jest darmowy, a jego kod jest jawny. Rozwijam go w wolnym czasie.

Obecnie jedynym kosztem projektu jest subskrypcja Claude Code - 100 zł miesięcznie. Pokrycie jej kosztów byłoby dla mnie wielką motywacją! Jest to całkowicie dobrowolne: niczego nie odblokowuje, a program działa tak samo dla wszystkich.

Wesprzyj na suppi.pl

Wpłatę obsługuje serwis suppi.pl (BLIK, przelew). Program AdMeNot nie wysyła tam żadnych danych.
